# Complete Guide to Keyboard Shortcuts - Mixko

**Mixko** was designed with full focus on accessibility and productivity through the use of the keyboard. Virtually all application actions have dedicated shortcuts.

---

## Main Navigation (Tabs and Feeds)

| Shortcut | Action |
| :--- | :--- |
| `Alt` + `1` | Go to the **Timeline** tab |
| `Alt` + `2` | Go to the **Notifications** tab |
| `Alt` + `3` | Go to the **Profile** tab (your own profile) |
| `Alt` + `4` | Go to the **DMs** tab (Direct Messages / Chat) |
| `Alt` + `5` | Go to the **Feeds and Lists** tab |
| `Alt` + `6` | Go to the **Saved Posts** tab (Bookmarks) |
| `Ctrl` + `F` or `Alt` + `7` | Go to the **Search** tab and focus on the search field |
| `Alt` + `S` or `Alt` + `8` | Go to the **Settings** tab |
| `Alt` + `9` | Go to the **Lists** tab |
| `Ctrl` + `1` to `8` | *(In Profile tab)* Switch between sub-tabs (Posts, Replies, Media, Likes, Lists, Starter Packs, Followers, Following) |
| `Alt` + `Shift` + `0` | Select main Feed (**Following**) on Timeline |
| `Alt` + `Shift` + `1` to `9` | Select saved Feeds (1st to 9th) on Timeline |

## Global and System Actions

| Shortcut | Action |
| :--- | :--- |
| `Alt` + `F1` | Open or close the **Help Menu** with shortcuts |
| `F5` | Quick reload of current tab |
| `Ctrl` + `Shift` + `E` | Toggle between **Dark Mode** and **Light Mode** |
| `Ctrl` + `Shift` + `P` | Open modal to go directly to a profile by handle (`@username`) |
| `Esc` | Close open modals or return to conversation list in DMs |

---

## Navigation in Post Lists and Profiles

| Shortcut | Action |
| :--- | :--- |
| `J` | Move focus to the next post/item (down) or load more posts at the end of the list |
| `K` | Move focus to the previous post/item (up) |
| `.` (Period) | Return focus to the first post at the top of the list |
| `P` | Open profile of the author of the focused post (or open selector for mentioned profiles) |
| `Shift` + `E` | Collapse expanded posts and reload current list |
| `A` | Open external link or the first link found in the focused post's text in browser |

---

## Interaction with Publications (Focused Post)

| Shortcut | Action |
| :--- | :--- |
| `N` | Create new post (open post composer modal) |
| `X` | Delete focused post (only for your own posts) |
| `L` | Like or unlike the focused post |
| `T` | Repost or undo Repost for the focused post |
| `Q` | Quote the focused post in a new publication |
| `R` | Reply to focused post (or focus message field in DM chat) |
| `E` | Expand and view the entire dialogue tree of the focused post |
| `V` | Play/pause video of focused post (and announce alternative description/alt text) |
| `Alt` + `C` | Copy URL/link of focused post on Bluesky to clipboard |
| `Shift` + `C` | Copy text of focused post to clipboard |
| `Shift` + `S` | Save or remove focused post from your **Saved Posts** (Bookmarks) |
| `Shift` + `L` | View list of users who liked the focused post in a modal |
| `Shift` + `T` | View list of users who reposted the focused post in a modal |
| `Shift` + `Q` | View list of posts quoting the focused post in a modal |
| `Shift` + `R` | View reply thread of the focused post in a modal |
| `Shift` + `O` | View original post of a quote in a modal |
| `Shift` + `F` | Pin the focused post on your profile |
| `Shift` + `M` | Mute focused post thread |
| `Alt` + `H` | Hide focused reply |
| `Alt` + `R` | Hide or show replies in Timeline (toggle preference) |
| `Alt` + `D` | Report focused publication or profile on display |

## Profiles, DMs, and Moderation

| Shortcut | Action |
| :--- | :--- |
| `Ctrl` + `Shift` + `D` | Start chat/DM directly with author of focused post or displayed profile (Profile must have messages enabled) |
| `S` | Follow profile (when on Profile tab) |
| `U` | Unfollow profile (when on Profile tab) |
| `M` | Mute author of focused post (or displayed profile) |
| `B` | Block author of focused post (or displayed profile) |
| `Ctrl` + `Shift` + `R` | *(In Notifications tab)* Switch between showing all notifications or only mentions |
| `Ctrl` + `Enter` | Publish post or send message (in composer modal or forms) |
| `Arrow Keys` / `Enter` | Navigate and select items in lists, menus, and modals |
