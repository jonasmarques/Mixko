# Guía Completa de Atajos de Teclado - Mixko

**Mixko** fue diseñado con un enfoque total en la accesibilidad y la productividad mediante el uso del teclado. Prácticamente todas las acciones de la aplicación cuentan con atajos dedicados.

---

## Navegación Principal (Pestañas y Feeds)

| Atajo | Acción |
| :--- | :--- |
| `Alt` + `1` | Ir a la pestaña **Línea de Tiempo** |
| `Alt` + `2` | Ir a la pestaña **Notificaciones** |
| `Alt` + `3` | Ir a la pestaña **Perfil** (su propio perfil) |
| `Alt` + `4` | Ir a la pestaña **DMs** (Mensajes Directos / Chat) |
| `Alt` + `5` | Ir a la pestaña **Feeds y Listas** |
| `Alt` + `6` | Ir a la pestaña **Publicaciones Guardadas** (Marcadores) |
| `Ctrl` + `F` o `Alt` + `7` | Ir a la pestaña **Búsqueda** y enfocar el campo de búsqueda |
| `Alt` + `S` o `Alt` + `8` | Ir a la pestaña **Configuración** |
| `Alt` + `9` | Ir a la pestaña **Listas** |
| `Ctrl` + `1` a `8` | *(En la pestaña Perfil)* Alternar entre subpestañas (Publicaciones, Respuestas, Multimedia, Me gusta, Listas, Paquetes de inicio, Seguidores, Siguiendo) |
| `Alt` + `Shift` + `0` | Seleccionar el Feed principal (**Siguiendo**) en la Línea de tiempo |
| `Alt` + `Shift` + `1` a `9` | Seleccionar Feeds guardados (del 1º al 9º) en la Línea de tiempo |

---

## Acciones Globales y del Sistema

| Atajo | Acción |
| :--- | :--- |
| `Alt` + `F1` | Abrir o cerrar el **Menú de Ayuda** con atajos |
| `F5` | Recarga rápida de la pestaña actual |
| `Ctrl` + `Shift` + `E` | Alternar entre **Modo Oscuro** y **Modo Claro** |
| `Ctrl` + `Shift` + `P` | Abrir modal para ir directamente a un perfil mediante handle (`@usuario`) |
| `Esc` | Cerrar modales abiertos o volver a la lista de conversaciones en DMs |

---

## Navegación en Listas de Publicaciones y Perfiles

| Atajo | Acción |
| :--- | :--- |
| `J` | Avanzar el enfoque a la siguiente publicación/elemento (hacia abajo) o cargar más publicaciones al final de la lista |
| `K` | Retroceder el enfoque a la publicación/elemento anterior (hacia arriba) |
| `.` (Punto) | Volver el enfoque a la primera publicación en la parte superior de la lista |
| `P` | Abrir el perfil del autor de la publicación enfocada (o abrir el selector de perfiles citados) |
| `Shift` + `E` | Contraer publicaciones expandidas y recargar la lista actual |
| `A` | Abrir enlace externo o el primer enlace encontrado en el texto de la publicación enfocada en el navegador |

---

## Interacción con Publicaciones (Publicación enfocada)

| Atajo | Acción |
| :--- | :--- |
| `N` | Crear nueva publicación (abrir modal de composición de publicación) |
| `X` | Eliminar la publicación enfocada (solo para sus propias publicaciones) |
| `L` | Dar me gusta o quitar me gusta a la publicación enfocada |
| `T` | Republicar o deshacer Republicación de la publicación enfocada |
| `Q` | Citar (*Quote*) la publicación enfocada en una nueva publicación |
| `R` | Responder a la publicación enfocada (o enfocar el campo de mensaje en el chat de DMs) |
| `E` | Expandir y visualizar todo el árbol de diálogo de la publicación enfocada |
| `V` | Reproducir/pausar el video de la publicación enfocada (y anunciar la descripción alternativa/texto alt) |
| `Alt` + `C` | Copiar la URL/enlace de la publicación enfocada en Bluesky al portapapeles |
| `Shift` + `C` | Copiar el texto de la publicación enfocada al portapapeles |
| `Shift` + `S` | Guardar o eliminar la publicación enfocada de sus **Publicaciones Guardadas** (Marcadores) |
| `Shift` + `L` | Visualizar lista de usuarios a los que les gustó la publicación enfocada en un modal |
| `Shift` + `T` | Visualizar lista de usuarios que republicaron la publicación enfocada en un modal |
| `Shift` + `Q` | Visualizar lista de publicaciones citando (*Quotes*) la publicación enfocada en un modal |
| `Shift` + `R` | Visualizar el hilo de respuestas de la publicación enfocada en un modal |
| `Shift` + `O` | Visualizar la publicación original de una cita (*Quote*) en un modal |
| `Shift` + `F` | Fijar la publicación enfocada en su perfil |
| `Shift` + `M` | Silenciar el hilo de la publicación enfocada |
| `Alt` + `H` | Ocultar la respuesta enfocada |
| `Alt` + `R` | Ocultar o mostrar respuestas en la Línea de Tiempo (alternar preferencia) |
| `Alt` + `D` | Denunciar la publicación enfocada o el perfil en pantalla |

## Perfiles, DMs y Moderación

| Atajo | Acción |
| :--- | :--- |
| `Ctrl` + `Shift` + `D` | Iniciar chat/DM directamente con el autor de la publicación enfocada o perfil en pantalla (El perfil debe tener los mensajes habilitados) |
| `S` | Seguir al perfil (cuando esté en la pestaña Perfil) |
| `U` | Dejar de seguir al perfil (cuando esté en la pestaña Perfil) |
| `M` | Silenciar al autor de la publicación enfocada (o al perfil en pantalla) |
| `B` | Bloquear al autor de la publicación enfocada (o al perfil en pantalla) |
| `Ctrl` + `Shift` + `R` | *(En la pestaña Notificaciones)* Alternar entre mostrar todas las notificaciones o solo menciones |
| `Ctrl` + `Enter` | Publicar entrada o enviar mensaje (en el modal de composición o formularios) |
| `Teclas de dirección` / `Enter` | Navegar y seleccionar elementos en listas, menús y modales |
