# Guia Completo de Atalhos de Teclado - Mixko

O **Mixko** foi projetado com foco total em acessibilidade e produtividade por meio do uso do teclado. Praticamente todas as ações da aplicação possuem atalhos dedicados.

---

## Navegação Principal (Abas e Feeds)

| Atalho | Ação |
| :--- | :--- |
| `Alt` + `1` | Ir para a aba **Timeline** |
| `Alt` + `2` | Ir para a aba **Notificações** |
| `Alt` + `3` | Ir para a aba **Perfil** (seu próprio perfil) |
| `Alt` + `4` | Ir para a aba **DMs** (Mensagens Diretas / Chat) |
| `Alt` + `5` | Ir para a aba **Feeds e Listas** |
| `Alt` + `6` | Ir para a aba **Posts Salvos** (Bookmarks) |
| `Ctrl` + `F` ou `Alt` + `7` | Ir para a aba **Busca** e focar no campo de pesquisa |
| `Alt` + `S` ou `Alt` + `8` | Ir para a aba **Configurações** |
| `Alt` + `9` | Ir para a aba **Listas** |
| `Ctrl` + `1` a `8` | *(Na aba Perfil)* Alternar entre sub-abas (Posts, Respostas, Mídia, Curtidas, Listas, Pacotes Iniciais, Seguidores, Seguindo) |
| `Alt` + `Shift` + `0` | Selecionar o Feed principal (**Seguindo**) na Timeline |
| `Alt` + `Shift` + `1` a `9` | Selecionar Feeds salvos (do 1º ao 9º) na Timeline |

---

## Ações Globais e do Sistema

| Atalho | Ação |
| :--- | :--- |
| `Alt` + `F1` | Abrir ou fechar o **Menu de Ajuda** com atalhos |
| `F5` | Recarregamento rápido da aba atual |
| `Ctrl` + `Shift` + `E` | Alternar entre **Modo Escuro** e **Modo Claro** |
| `Ctrl` + `Shift` + `P` | Abrir modal para ir direto a um perfil pelo handle (`@usuario`) |
| `Esc` | Fechar modais abertos ou voltar à lista de conversas em DMs |

---

## Navegação em Listas de Posts e Perfis

| Atalho | Ação |
| :--- | :--- |
| `J` | Avançar foco para o próximo post/item (para baixo) ou carregar mais posts ao fim da lista |
| `K` | Voltar foco para o post/item anterior (para cima) |
| `.` (Ponto) | Voltar o foco para o primeiro post no topo da lista |
| `P` | Abrir perfil do autor do post em foco (ou abrir seletor de perfis citados) |
| `Shift` + `E` | Recolher postagens expandidas e recarregar a lista atual |
| `A` | Abrir link externo ou o primeiro link encontrado no texto do post em foco no navegador |

---

## Interação com Publicações (Post em foco)

| Atalho | Ação |
| :--- | :--- |
| `N` | Criar nova publicação (abrir modal de composição de post) |
| `X` | Excluir a publicação focada (apenas para suas próprias postagens) |
| `L` | Curtir ou descurtir o post em foco |
| `T` | Repostar ou desfazer Repost do post em foco |
| `Q` | Citar (*Quote*) o post em foco em uma nova publicação |
| `R` | Responder ao post em foco (ou focar no campo de mensagem no chat de DMs) |
| `E` | Expandir e visualizar toda a árvore de diálogo do post em foco |
| `V` | Reproduzir/pausar o vídeo do post em foco (e anunciar a descrição alternativa/alt text) |
| `Alt` + `C` | Copiar a URL/link do post em foco no Bluesky para a área de transferência |
| `Shift` + `C` | Copiar o texto do post em foco para a área de transferência |
| `Shift` + `S` | Salvar ou remover o post em foco dos seus **Posts Salvos** (Bookmarks) |
| `Shift` + `L` | Visualizar lista de usuários que curtiram o post em foco em um modal |
| `Shift` + `T` | Visualizar lista de usuários que deram Repost no post em foco em um modal |
| `Shift` + `Q` | Visualizar lista de postagens citando (*Quotes*) o post em foco em um modal |
| `Shift` + `R` | Visualizar a thread de respostas do post em foco em um modal |
| `Shift` + `O` | Visualizar o post original de uma citação (*Quote*) em um modal |
| `Shift` + `F` | Fixar a publicação focada no seu perfil |
| `Shift` + `M` | Mutar/Silenciar a thread da publicação focada |
| `Alt` + `H` | Ocultar a resposta focada |
| `Alt` + `R` | Ocultar ou exibir respostas na Timeline (alternar preferência) |
| `Alt` + `D` | Denunciar a publicação focada ou o perfil em exibição |

---

## Perfis, DMs e Moderação

| Atalho | Ação |
| :--- | :--- |
| `Ctrl` + `Shift` + `D` | Iniciar chat/DM diretamente com o autor do post em foco ou perfil em exibição (O perfil deverá ter mensagens habilitadas) |
| `S` | Seguir o perfil (quando na aba Perfil) |
| `U` | Deixar de seguir o perfil (quando na aba Perfil) |
| `M` | Silenciar o autor do post em foco (ou o perfil em exibição) |
| `B` | Bloquear o autor do post em foco (ou o perfil em exibição) |
| `Ctrl` + `Shift` + `R` | *(Na aba Notificações)* Alternar entre exibir todas as notificações ou apenas menções |
| `Ctrl` + `Enter` | Publicar post ou enviar mensagem (no modal de composição ou formulários) |
| `Setas` / `Enter` | Navegar e selecionar itens em listas, menus e modais |
